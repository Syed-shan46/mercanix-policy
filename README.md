3. In the left sidebar, click **Pages** (under "Code and automation").
4. Under **Build and deployment** &rarr; **Branch**:
   - Source: **Deploy from a branch**
   - Branch: `main` / `/(root)`

## ✨ Tracking App Features & Compliance Disclosures Covered

- **Real-Time Consignment Tracking:** Explicit disclosure on how Order IDs, Business Profile IDs, and tracking tokens are queried via `https://hiracrm.in/api/tracking/:token`.
- **6-Stage Logistics Milestone Lifecycle:** China Warehouse Receipt &rarr; Dispatched from China &rarr; Destination Port / India Arrival &rarr; Customs Clearance &rarr; Out for Delivery &rarr; Consignment Delivered.
- **Cargo Specification Visibility:** Clear handling of gross weight (kg), volume (CBM), shipping marks, air/sea freight methods, and carrier airway bills.
- **On-Device Search History:** Discloses local storage of recent query tokens with immediate in-app 1-tap clearance.
- **Zero Invasive Permissions:** Discloses only `INTERNET` and `ACCESS_NETWORK_STATE` for API connectivity, plus external intent launchers for WhatsApp and direct phone calling (`+91 90720 14777`). No location, contacts, camera, or SMS permissions required.
- **Zero Financial Data Collection:** Clarifies that the tracking application does not collect credit cards, UPI PINs, or banking credentials.
- **Interactive Data Erasure Assistant:** Pre-filled mailto and WhatsApp assistant for users requesting CRM record erasure.
- **Modern Responsive Design:** Table of contents scroll-spy, real-time keyword search filter, dark/light theme switch, and print-to-PDF formatting.
